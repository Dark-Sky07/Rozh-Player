# ROZH Player 1.1.4

**Corrected Android fullscreen sizing and controls**

## Android fullscreen fix

- Replaced the fixed fullscreen stage nested inside the animated player view with a full-viewport Android player layout. This avoids clipping by the app's view/overflow containers after landscape rotation.
- Explicitly sizes the app shell, player view, stage, and video against the available landscape viewport; the complete video stays visible with aspect-correct `contain` sizing.
- Keeps controls and playback menus responsive above the fullscreen stage and preserves the normal idle fade behavior.
- Fullscreen exit restores the regular app layout and system bars.

## Compatibility

- Version is bumped to 1.1.4 and Android `versionCode` to 1001004. The Android signing identity is unchanged; v1.1.3 installations can update in place.
- The existing release workflow and attached asset convention are unchanged.

## Validation

- `npm run build` and `git diff --check` must pass before merge.
- Web, Rust, Android bridge, and release builds are validated by protected CI. No physical Android phone/TV is available in this environment, so fullscreen crop, touch controls, and OEM-specific rotation behavior need confirmation on-device.
