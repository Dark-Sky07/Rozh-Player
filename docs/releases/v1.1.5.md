# ROZH Player 1.1.5

**A usable, remote-first Android TV launch and media-browsing flow**

## Android TV

- The dedicated TV package now embeds an explicit startup flag and keeps the 10-foot interface enabled even if a migrated preference says TV mode is off. The release workflow checks this flag in the actual production frontend before packaging.
- Android TV always indexes device media on launch, and TV "Choose folder" / library Add actions use Android's native Storage Access Framework folder picker rather than the Android WebView file input, which is not a dependable remote-first file browser. The selected folder is indexed, media remains on the TV home/library, and D-pad focus is restored after rescans.
- Folder-picker errors, cancellation, and indexing completion now return visible feedback instead of leaving the action apparently inert.

## Compatibility and upgrades

- Android version code is incremented to 1001005. The Android signing identity remains the current release identity, so v1.1.4 installs can update in place.
- Existing media and app data are not removed by the update.

## Validation

- `npm ci`, `npm run typecheck`, and production builds with and without `VITE_TV_BUILD=1` passed. The TV frontend build emitted `data-tv-build="1"`.
- The release workflow must pass protected CI, Android/TV builds, signing, and artifact verification before publication.
- This sandbox has no physical Android TV. D-pad behavior, SAF picker compatibility across TV vendors, and actual video playback still require confirmation on a real device; this release does not claim physical-device verification.
