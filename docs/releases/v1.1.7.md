# ROZH Player 1.1.7

**Favorites, personal playlists, and IPTV playlist import**

## Media organization

- Added persistent Favorites and personal playlists to the Android TV library and navigation rail. Existing phone, desktop, and web library layouts remain unchanged.
- Playlists can be created with a custom name, deleted, and edited by adding or removing library items. **Play playlist** queues entries in order and advances automatically, stopping at the end unless repeat-all is enabled.
- Added a Favorites shelf to Android TV Home.
- Removing media from the library or pruning files no longer present on Android also cleans obsolete playlist references.

## Streams and IPTV

- Added M3U/M3U8 import from a local file or HTTP(S) URL. Imports are limited to 5 MiB and 500 channels, accept HTTP(S) channel links, and retain common channel names, groups, and logos.
- Imported channels are saved to the normal media library and a named playlist; playback uses ROZH's existing stream pipeline.
- Android TV uses the native HTTP plugin for remote playlist retrieval. Web/PWA and non-TV UI flows are unchanged.
- This release does not add XMLTV/EPG, tuner, recording, provider API, or Kodi add-on support.

## Compatibility and validation

- Android version code: **1001007**. Compatible v1.1.6 Android installations can update in place with the current release signing identity. Application version **1.1.7** is synchronized across web, Tauri, and Cargo metadata.
- Validated with `npm ci`, TypeScript typecheck, production web build, and targeted M3U parser checks. The existing Vite mixed-import warnings remain non-fatal.
- Release CI is responsible for the Android, Windows, macOS, and Linux artifacts. Real Android TV D-pad, SAF, codec, and installer validation still requires the user's device; no physical TV is available in this build environment.
