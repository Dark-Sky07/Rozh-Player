# ROZH Player 1.1.6

**A dedicated Android TV media-center interface**

## Android TV

- Replaced the horizontal TV header with a separate, remote-first vertical media-center rail. It now has direct Home, All Media, Video, Music, Streams, History, and Settings destinations; the video/music destinations open the correct library filter.
- Moved source actions into the rail: scan, native folder selection on Android TV, and network URL entry. The player remains a separate immersive destination and the rail stays out of the way during playback.
- Kept the TV shell isolated from phone, desktop, and web layouts.

## Kodi research and scope

- Reviewed Kodi's native architecture and its Estuary Home, video/music navigation, source/file browser, fullscreen OSD, player controls, media-source dialog, settings, and Android build guide. Added `docs/ANDROID_TV_MEDIA_CENTER.md` with findings, feature gaps, licensing boundaries, and the staged roadmap.
- This is an original ROZH interface informed by Kodi's living-room patterns, not a claim of complete Kodi parity. Kodi's scraper/database, PVR/DVR/EPG, add-on runtime, photos, games, and power integrations are not represented as working features. No Kodi code or branded assets were copied.

## Compatibility and validation

- Android version code is 1001006. Existing v1.1.5 Android installations can update in place using the current signing identity.
- `npm ci`, TypeScript checking, and the dedicated TV production build are required to pass CI before this public release. Physical Android TV remote and playback testing is still necessary.
