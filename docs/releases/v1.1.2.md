# ROZH Player 1.1.2

**More reliable Android phone and Android TV media libraries**

## Android phone and Android TV fixes

- Fixed a mailbox race that could make a new launch or manual library scan reuse the previous scan's completed state. Each scan now carries a request ID, so only its own completed result is merged into the library.
- Prevented an old mailbox command from being replayed when the app process restarts; stale commands could otherwise reopen an external player or update installer.
- Refresh the native bridge's Activity reference after Android recreates the app Activity, keeping permission, folder-picker, and installer callbacks attached to the live screen.
- Made the Android audio-index setting apply to both MediaStore and previously selected folders. Missing provider MIME types are classified by filename so audio is not mislabeled as video.
- A user who grants video access but declines the separate audio permission on Android 13+ can still scan and play videos.
- Added Android 14+ selected-media permission support, allowing the device index to use the videos the user explicitly selected.
- Fixed library de-duplication to use the stable Android document URI. Two files with identical names and sizes in different folders now remain separate library entries.

## Compatibility

- Version is bumped to 1.1.2 and Android `versionCode` to 1001002. Phone and TV release APKs use the replacement signing identities introduced in v1.1.1.

## Validation

- `npm run build` and `git diff --check` passed locally.
- Rust and Android native builds must pass the protected pull-request and release workflows before publication. This sandbox does not provide Cargo, the Android SDK, or physical Android phone/TV devices; device playback, permissions, and remote behavior are not claimed as physically tested.
