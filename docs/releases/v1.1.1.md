# ROZH Player 1.1.1

**Security signing transition and safer release validation**

### Install and update notice

This release introduces new desktop updater and Android sideload signing identities after the previous signing material was exposed. Existing desktop users must install this release manually once; the in-app updater will use the new identity for later updates.

Existing Android phone/tablet and Android TV sideload installations signed with the previous certificate must be uninstalled before installing these APKs. Uninstalling may erase ROZH Player's app-private settings, history, and playlists; back them up first if available. Media files stored elsewhere on the device are not removed. Future Android sideload updates use the new stable signing key.

The Android AAB files are supplied as build artifacts for a separate Play Console submission; this GitHub release does not publish to Google Play. Confirm the Play App Signing and upload-key configuration before submitting them.

### Security and release pipeline

- Replaced the embedded Tauri updater public key with the new key for future signed desktop updates.
- Uses newly provisioned Android signing material; release builds fail closed if the key or password is missing or invalid.
- Release assets are published atomically only after all desktop, Android, Android TV, web, signing, and updater-manifest jobs succeed.
- Main-branch protections require a pull request and passing Web, Rust, and Android checks, and block force-pushes and branch deletion.
- Includes the repository-wide native media and release-pipeline hardening documented in the security audit.

### Platforms

Windows 10/11, macOS, Linux, Android phones/tablets, Android TV (dedicated package), and Web/PWA.

### Validation

- Local web typecheck and production build passed. The release workflow must pass all native builds, signing, and artifact validation before it creates the public release.
- Physical-device update migration and Play Console submission are not certified by CI. Follow the install notice above and validate store signing separately.
