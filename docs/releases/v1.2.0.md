# ROZH Player 1.2.0

**Quality-first playback, local metadata scraping, and lossless IPTV recording**

## What's new

- Added a movie/TV metadata search in the library. Series results come from TVmaze and movie results from Apple Search; selected title, year, summary, genres, rating/artwork (when available) are saved in the local library. No API key is required; network access is needed to search.
- Added manual desktop IPTV recording from Streams and the XMLTV Guide. FFmpeg copies the incoming audio/video streams to Matroska (`.mkv`) without decoding or re-encoding, so this recording path does not introduce quality loss. The app must stay open; only one HTTP(S) recording can run at a time.
- Changed desktop compatibility fallback to prioritize source fidelity: first attempt direct playback, then lossless stream-copy remux for compatible H.264/AAC sources. ROZH never silently re-encodes on this path.
- If a file still needs conversion (for example unsupported HEVC/H.265/x265), ROZH asks before proceeding. The optional compatibility conversion uses H.264 CRF 16 and AAC 320 kbps, preserves the original file, and may still alter quality. AAC audio is copied when compatible.
- Expanded recognized video containers, raw H.264/HEVC extensions, and common AC-3/E-AC-3/DTS audio formats.

## Limits and quality notes

- There is no universal lossless way to make every codec playable in every WebView: a decoder must understand the source bitstream, or a conversion is required. Declining conversion preserves the source and avoids re-encoding, but playback may remain unavailable on a device without that codec.
- A compatibility transcode is inherently not guaranteed bit-exact. The confirmation explains this; the source file is never overwritten. Web/PWA uses the browser's own decoders. Android depends on the system decoder or external-player handoff.
- IPTV recording is manual, desktop-only, and requires the app to remain running. This is not a tuner integration or EPG-scheduled DVR. Provider availability, network stability, and FFmpeg/container compatibility still apply.
- The metadata scraper covers TVmaze series and Apple movie catalog results, not every country, language, release, or media type.
- Arbitrary third-party add-on code remains disabled until a secure sandbox and permission model exist.
