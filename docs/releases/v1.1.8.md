# ROZH Player 1.1.8

**Android TV media-center update** — XMLTV programme guides and a local pictures gallery join the existing IPTV, playlists, favorites, and remote-first TV experience.

## What's new

- Import an XMLTV guide URL with an IPTV playlist, or read `url-tvg`, `x-tvg-url`, and `tvg-url` from the M3U header.
- Match XMLTV channels by `tvg-id`, with channel display-name fallback; cache guide data locally and show current/next programmes.
- Add a Pictures destination to the Android TV shell. Select local image files, browse the gallery, and view images with remote-friendly previous/next controls.
- The dedicated Android TV build indexes MediaStore images and images under user-selected folders. Phone library behavior remains unchanged.

## Limits

- XMLTV is programme information only; catch-up streams and recording are not provided.
- PVR/DVR requires a supported tuner/capture backend and storage permissions that are not available in the current architecture.
- Third-party add-on scripts remain disabled because ROZH does not yet have a secure extension sandbox or permission model.
- A general movie/TV metadata scraper is not included in this release; no third-party metadata API credentials or provider contract are configured.
- Playback and image decoding remain subject to the provider, network, Android WebView/OS, and device capabilities.

## Upgrade notes

- Version **1.1.8** is synchronized across package, Tauri, and Cargo metadata; Android version code is **1001008**.
- The Android TV image index requests image permission only in the dedicated TV package; users may also grant folder access through Android's document picker.
- Install packages only from the official release page. Release assets and checksums will be listed there after the signed release workflow completes.
