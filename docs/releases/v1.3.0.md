# ROZH Player 1.3.0

**EPG-scheduled desktop recordings and safe source-pack add-ons**

## What's new

- Added EPG scheduling for the next programme on an imported IPTV channel. Choose an output file at schedule time; ROZH starts/stops a stream-copy recording at the programme's XMLTV times.
- Scheduled jobs persist across ROZH restarts. If ROZH is opened during a scheduled programme, it attempts a catch-up start and records until the listed end time. Conflicting jobs are rejected; recordings remain stream-copy into MKV with no re-encoding.
- Added an install/remove manager for JSON source packs (`rozh.source-pack/v1`). Packs may declare M3U and XMLTV URLs and are imported only after the user selects a source. No scripts, binaries, executable modules, or automatic network fetches are run from a pack.
- Added scheduling status and cancellation to Guide and documented the source-pack schema in `docs/ADDONS.md`.

## Operational limits

- Scheduled recording requires the desktop app to be running and the device awake at programme time; closing ROZH or suspending the computer stops recording. This is not an OS background service.
- EPG scheduling works only for HTTP(S) IPTV streams with valid XMLTV programme times. It does not add a tuner, capture card, satellite/cable input, or platform-specific device permissions.
- One FFmpeg recording can run at a time. Concurrent scheduled slots are rejected. The provider must keep the stream available for the entire programme.
- Source packs are deliberately data-only extensions for IPTV playlist/EPG sources, not a general-purpose executable add-on API. Native code, JavaScript, WebAssembly, and arbitrary scripts are not executed.
- HEVC/x265 playback still depends on the OS/WebView or external decoder. Lossless playback cannot be guaranteed on hardware lacking a compatible decoder; any desktop conversion remains explicit opt-in and may alter quality.

## Upgrade notes

- Version **1.3.0** is synchronized across package, Tauri, and Cargo metadata; Android version code is **1003000**.
- Manual recording, quality-first fallback, metadata search, Android TV guide, and previous v1.2.0 features remain included.
- Scheduled recordings are local to this installation and are not cloud-synchronized.
