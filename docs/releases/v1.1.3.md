# ROZH Player 1.1.3

**Reliable immersive fullscreen playback on Android**

## Android playback fixes

- Android phone and Android TV video playback automatically enters fullscreen in landscape after playback actually begins.
- Uses ROZH's in-app fullscreen layer instead of Android WebView's inconsistent native fullscreen handling, so the sidebar, app bars, and bottom navigation cannot remain over the video.
- Hides Android system bars during fullscreen and restores them on exit. The dedicated Android TV package remains landscape when fullscreen is exited.
- Playback controls fade after a short idle period and reappear with touch, keyboard, or remote activity.
- Fixed fullscreen menu stacking so subtitle, playback, and other settings drawers stay visible and interactive above video. Android Back exits fullscreen instead of leaving playback unexpectedly.
- Orientation updates use a separate native control mailbox, so a long-running device media scan cannot delay rotation or system-bar changes.

## Compatibility

- Version is bumped to 1.1.3 and Android `versionCode` to 1001003. The existing replacement signing identities remain unchanged so v1.1.2 users can update in place.
- Release assets continue to be uploaded by the existing atomic release workflow using the same attached-assets convention; no release workflow or asset naming changes are introduced.

## Validation

- `npm run typecheck`, `npm run build`, and `git diff --check` are required before merge.
- Android native bridge compilation and Rust checks are required in protected CI. No physical Android phone or TV is available in this environment, so rotation, system bars, remote Back, and playback menus still need on-device confirmation.
