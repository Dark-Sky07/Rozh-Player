# ROZH Player 1.3.1

**Android TV startup and remote-first interface reliability**

## What's fixed

- The dedicated Android TV package now identifies itself to the frontend through its native `.tv` application identity as well as the embedded Vite build flag. A stale or incorrectly rebuilt web bundle can no longer silently open the phone-style blank player view in the TV package.
- Platform detection is resolved before the application shell is loaded, so the TV home screen, navigation, large-screen styling, and D-pad focus behavior are selected on the first render.
- Android TV releases now verify that the actual APK contains the TV frontend marker before signing and publishing. A packaging regression fails the release instead of shipping a phone-style UI under the TV name.
- Runtime TV detection also applies the TV visual theme when a device is identified by its TV user-agent or build target.

## Upgrade notes

- Version **1.3.1** is synchronized across package, Tauri, and Cargo metadata; Android version code is **1003001**.
- Install **ROZH Player TV** (`ROZH-Player-TV-1.3.1.apk`) on Android TV. The standard Android phone APK remains a separate package.
- The update preserves existing media and settings. No media is transcoded or modified.
